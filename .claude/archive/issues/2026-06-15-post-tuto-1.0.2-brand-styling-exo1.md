## Contrainte qui motive le report

Le paquet **`tutoquartotypst` 1.0.1 est déjà publié et installé** par une partie des
participants (communication faite en amont). Or `pkg/inst/exercices/` est une **copie**
de `exercises/` : starters posés par `installer_exercices()` **et sources des
corrections** posables via `recuperer_correction()`. Toucher à `exercises/` = soit
re-sync le paquet (nouvelle version, trop tard la veille), soit créer une divergence
paquet-installé / repo (casse aussi le garde-fou CI `pkg-sync-check`).

→ **Avant le tuto** : on n'agit que sur le **site** (pages exo + slides, hors paquet).
→ **Après le tuto** : on peut livrer une **1.0.2+** avec les vrais changements de fichiers.

## Le problème de fond (rappel)

La correction de l'exo 1 (`exercises/01-document-typst/correction/rapport-starwars.qmd`)
embarque **tout le « Bonus B4 » de l'exo 2** (câblage R `brand.yml` : `styliser_brand()`,
`theme_brand_gt`, `theme_brand_ggplot2`, surlignage Jabba, + `#highlight(...)`{=typst}
qui ouvre une 3e voie d'accès à la charte) **sans qu'aucune des 4 étapes ne le demande
ni ne l'annonce**. Un·e débutant·e qui ouvre cette correction comme filet de secours
tombe sur ~40 lignes de R jamais enseignées → faux sentiment d'échec, B4 spoilé.

Racine : la dichotomie **auto** (`_brand.yml` lu par Quarto/Typst → mise en page :
liens, fond, polices, titres) **vs câblé-main** (sorties R `gt`/`ggplot` → à brancher
soi-même en R via le paquet `brand.yml`) n'est nommée nulle part en Bloc 1.

L'exo 2, lui, est exemplaire (B4 balisé bonus optionnel, étape 3 prévient « tableaux
restent bruts », corrections étiquetées `# --- Bonus B4 (optionnel) appliqué ---`).

## À faire en 1.0.2+ (touche `exercises/`, donc le paquet)

1. **Aligner la correction de l'exo 1 sur ses étapes.** Deux options à trancher :
   - **Alléger** : retirer le câblage R gt/ggplot → la correction = exactement les
     4 étapes (tableaux/graphes bruts). B4 redevient exclusif à l'exo 2. Le plus propre.
   - **Scinder** : `rapport-starwars.qmd` strict (4 étapes) + `rapport-starwars-bonus.qmd`
     brandé ; le filet 🆘 pointe le strict. Touche `justfile`/recette `exos`.
   - (À défaut : garder le rendu riche mais **baliser dans le fichier** avec un bandeau
     « va plus loin que les 4 étapes = Bonus B4 ». Moins propre que sur le site, mais
     utile pour qui passe par `recuperer_correction()`.)
2. **`pkg/NEWS.md`** (n'existe pas aujourd'hui) : entrée rétro `1.0.1` (« version jouée
   au tuto RR 2026 ») + entrée `1.0.2` décrivant le nettoyage exo 1.
3. **Bump `pkg/DESCRIPTION` → 1.0.2**, `just pkg-sync` + `pkg-sync-check` vert.
4. Vérifier que les retouches site (pré-tuto) et le fichier ne se contredisent pas
   (anti-dérive index ↔ boussole, et site ↔ correction).
